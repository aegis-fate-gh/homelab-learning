# homelab-learning
This repo contains both projects and planning for future iterations of my homelab, and just things I decided to try out. A lot of it serves as a proving and testing ground for future features and capabilities for my homelab.

Each main folder is numbered sequentially. Followed by a name that covers the overarching idea. There are also likely other folders within each folder that will be used to break down projects into smaller steps that get progressively more complex.

Folders numbered 999 are basically ideas that graduated beyond just being a concept in Notion, but have yet to be started.
